# GastoFácil — Landing page

Sitio web informativo de **GastoFácil**, plataforma SaaS multi-tenant para la
administración de pagos de gastos comunes en comunidades habitacionales.

- `index.html` — contenido (propósito, funciones, ventajas, cómo funciona, roles, FAQ, contacto)
- `styles.css` — estilos, responsive sin dependencias
- `script.js` — menú móvil y año dinámico

Sitio 100% estático, sin build. Vista previa local:

```bash
python3 -m http.server 8000
```

La plataforma está en https://gastofacil.femedinare.tech/ y el proyecto es de
[Mastema Tech Solutions](https://mastema.tech).
